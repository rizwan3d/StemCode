# Introducing StemCode: AI coding that stays close to your code

**StemCode is an open-source, local-first AI coding agent for your real repository.** Work from the terminal, desktop, your editor, or CI—without moving your project into a separate hosted workspace.

Whether you are exploring an unfamiliar codebase or shipping a change, StemCode can help you inspect files, plan work, make tracked edits, run validations, and review the result.

## Built for the way developers work

- **Start in your own repository.** Search files, follow code intelligence, and use the tools already installed in your environment.
- **Make changes you can inspect.** Use targeted patches and tracked edits, with undo and redo for supported changes.
- **Stay in control.** Permission prompts and profiles distinguish tasks that may run automatically from those that require approval.
- **Move across workflows.** Use the same agent from the CLI, desktop app, VS Code, Visual Studio, JetBrains integrations, and CI code review.
- **Keep context visible.** Store reusable commands and project memory in reviewable `.stemcode/` files.
- **Choose your AI provider.** Configure supported API-key, sign-in, OpenAI-compatible, or local-model options. Your chosen provider may receive the prompt and selected context required for a request.

## Try StemCode

Install the command-line app:

```bash
npm install -g stemcode
cd your-project
stemcode
```

Prefer a visual interface? Download the [latest desktop release](https://github.com/rizwan3d/StemCode/releases/latest) for Windows, macOS, or Linux.

Use an editor? See the [VS Code extension](https://marketplace.visualstudio.com/items?itemName=growbitlab.stemcode-vscode) or [Visual Studio extension](https://marketplace.visualstudio.com/items?itemName=growbitlab.stemcode-vs).
